Overview

IT Support Associate at Gracious Exports — an export trading company based in Mumbai. Responsible for first-level IT support covering end-user computing, email systems, software configuration, asset management and network connectivity across the organisation.

Core Responsibilities

  • Provided first-level desktop, laptop and printer troubleshooting for all end users — covering hardware faults, OS issues, driver management, and peripheral connectivity.
  • Assisted employees with Microsoft Office support — resolving issues with Word, Excel, Outlook and other Office 365 applications used daily by the team.
  • Handled email login configuration using Outlook, IMAP, and SMTP — setting up new accounts, troubleshooting send/receive issues, and configuring email clients on multiple devices.
  • Performed basic system setup and software installation for new user machines — OS configuration, driver installation, security software deployment and initial user account setup.

  • Managed IT asset inventory tracking — recording hardware details, assignment information, and coordinating hardware repairs with vendors.
