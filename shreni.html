Overview

IT Associate Manager at Shreni Shares Limited — a SEBI / NSE / BSE regulated brokerage operating in the BFSI sector. Responsible for the full IT infrastructure supporting live trading operations, back-office systems and end-user computing across the organisation.

Core Responsibilities

  • Provide Level 1 & Level 2 IT support for desktops, laptops, printers, and trading workstations within a SEBI / NSE / BSE regulated BFSI environment.
  • Ensure smooth functioning of live trading and back-office systems, providing technical support during market hours when downtime has direct financial consequences.
  • Perform BOD (Beginning of Day) and EOD (End of Day) activities — system health checks, connectivity verification, and readiness validation for all trading applications before and after market hours.
  • Administer and support the MoneyMaker trading platform — user access management, issue troubleshooting, and ensuring system readiness during trading hours.
  • Support network operations including LAN troubleshooting, IP configuration, DNS checks, and internet/proxy configuration for all workstations.
  • Manage endpoint security — antivirus installation, updates, and monitoring across all user systems to enforce organisational security policies.
  • Provide Active Directory support — user account management, password resets, group policy administration, and access control for all staff.
  • Assist with data backup operations and recovery procedures to ensure data protection and system availability in line with compliance requirements.
  • Maintain IT asset inventory — hardware provisioning, tracking, and lifecycle management across all departments.
  • Coordinate with third-party vendors for hardware repairs, warranty services, and infrastructure support including escalation and follow-up.
  • Provide EPBAX support for internal telephony systems and troubleshoot communication issues across the office.
  • Maintain technical documentation and operational records — supporting compliance and IT reporting within the financial regulatory environment.

Key Skills Demonstrated

L1 & L2 IT Support Active Directory Windows Server BOD / EOD Operations MoneyMaker Platform LAN / WAN DNS / DHCP Endpoint Security Data Backup & Recovery EPBAX Support IT Asset Management Vendor Coordination Proxy Configuration Technical Documentation Compliance Reporting

Regulatory Environment

  • Operating within a SEBI regulated brokerage — all IT operations must comply with SEBI guidelines on system uptime, data security and incident response.
  • Supporting systems connected to NSE (National Stock Exchange) and BSE (Bombay Stock Exchange) — any technical failure during market hours requires immediate escalation and resolution.
  • Maintaining compliance documentation and IT audit trails as required by financial regulatory standards for BFSI sector organisations.
